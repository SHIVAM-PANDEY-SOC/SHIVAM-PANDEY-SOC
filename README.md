# GitHub Contribution Snake (GitHub Action)

Create the file:

```
.github/workflows/snake.yml
```

Paste this workflow:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */12 * * *"

  workflow_dispatch:

jobs:
  build:

    runs-on: ubuntu-latest

    permissions:
      contents: write

    steps:

      - uses: Platane/snk@v3

        with:
          github_user_name: SHIVAM-PANDEY-SOC
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v4

        with:
          target_branch: output
          build_dir: dist

        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
